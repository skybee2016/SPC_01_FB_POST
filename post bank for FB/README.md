# Post bank for FB

Ready-to-publish Facebook posts for the Senior Peace Care page (seniorpeacecare.com).

Each post gets its own folder: `YYYYMMDD_HHMMSS/` containing `post.json` (headline, caption, hashtags, CTA, image prompt) and `image.png`.

Posts are added here by the autopost run, and published posts are marked `"published": true`.
